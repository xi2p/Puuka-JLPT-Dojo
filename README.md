# Puuka JLPT Dojo / プーカ JLPT 道場

<p align="center"><img src="public/puuka.png" alt="プーカ" width="160"></p>

如果你在备考JLPT时，不想把历年卷打印成纸质，又觉得直接对着PDF文件做题很不舒服，那么本项目可能适合你。

Puuka JLPT Dojo 是一个在电脑浏览器中使用的 JLPT 真题练习工具。
项目目前提供59 套 N1、N2 试卷。

**注意：本项目仅供浙江大学同学学习使用！** 试题下载功能需要连接学校内网的ZJU Git平台，只有使用校园内网环境才可以下载试题数据。

![试卷列表与下载入口](docs/screenshots/home.png)

## 功能

- **试卷下载**：在ZJU内网环境下可以便捷地下载项目提供的试题数据。
- **阅读与答题**：查看文章、注释、表格和关联小题，通过选项或答题卡作答。
- **保存进度**：网站会记录答案、笔记、待检查标记、用时和听力位置，可以分多次完成一份试卷。
- **听力练习**：音频支持暂停、变速；交卷后可按小题定位播放，并查看听力原文。
- **交卷复盘**：查看正确、错误和未答题，统计各部分答对题数与正确率。
- **重复练习**：同一套试卷可以重新作答，之前的作答记录仍可查看。
- **管理作答记录**：进行中和已交卷的练习都列在记录中，可以继续上次作答，也可以单独删除某次记录。

## 安装与启动

以下步骤适用于 Windows。

1. [下载程序 ZIP](https://github.com/xi2p/Puuka-JLPT-Dojo/archive/refs/heads/master.zip)，完整解压到固定文件夹，例如 `D:\Puuka-JLPT-Dojo`。 **请不要在压缩包内运行！**
2. 第一次运行前，请双击启动 **部署网站.cmd**，按提示等待部署完成。首次部署可能需要联网下载运行所需的组件。
3. 双击 **启动网站.cmd**，浏览器会打开 <http://127.0.0.1:3300> 网页。
4. 在首页选择需要的试卷，下载完成后点击「开始作答」。

后续使用时，直接运行 **启动网站.cmd** 即可，不需要重复部署。

**使用期间请保持服务窗口（一个黑色的终端窗口）开启。** 使用结束后，请先点击「保存并退出」，再关闭服务窗口，否则当前答题进度可能不被保存。

## 下载和管理试卷

程序下载包不含试卷和音频。首次打开时，需要连接ZJU内网下载想做的试卷。

- 点击「刷新远端目录」，查看可下载的试卷。
- 标为「已下载」的试卷可以直接作答；标为「有更新」的试卷可以选择更新。
- 「移除本机文件」只删除该卷的试题和音频，保留答案、笔记和作答记录。以后重新下载该卷即可继续使用这些记录。

全部题库音频约 1.5 GB，不必一次下载。下载前可查看所选试卷的大小，并预留足够空间。

刷新目录、下载试卷和安装更新需要网络；已下载试卷的日常练习不需要联网。

## 作答与成绩

作答页面中，每页展示一组「問題」。遇到不确定的内容，可以点击题号下方的空心小旗，标记为稍后检查，或在笔记中记录。标记后小旗变为实心，再次点击可取消。

计时功能会记录练习用时，但**不会到时自动交卷**。确认交卷后，该轮答案锁定；需要重做时，请开始新一轮。

成绩页面会显示答对题数和正确率，**但不会换算 JLPT 官方分数，也不判断是否合格（因为JLPT采取「尺度得点」）**。

详细操作见[使用指南](docs/USER-GUIDE.md)。

## 更新程序

在首页点击「更新程序」，或在「设置与备份」中点击「检查更新」，确认后安装。也可以关闭服务窗口后，双击 **更新网站.cmd**。

更新完成后，重新运行 **启动网站.cmd**，再刷新网页。如果仍显示旧页面，可按 `Ctrl+F5` 尝试刷新。

程序更新会保留已下载试卷和个人作答记录。

## 常见问题

- **网页打不开**：检查服务窗口是否仍在运行，尝试重新启动，再打开 <http://127.0.0.1:3300>。
- **下载或更新失败**：程序更新需能访问[GitHub](https://github.com/xi2p/Puuka-JLPT-Dojo)；题库下载需能访问[浙大 GitLab](https://git.zju.edu.cn/3240104224/puuka-jlpt-dojo-lib)，校外访问请按学校网络要求连接。已有试卷仍可离线练习。
- **进度找不到**：确认使用的是原来的程序文件夹，并在首页「作答记录」中查找。不要急着清理数据或重新安装；有备份时可先备份当前记录，再导入旧备份。

更多问题见[使用指南](docs/USER-GUIDE.md#常见问题)。维护者请参阅[维护说明](docs/LIBRARY-MANAGEMENT.md)和[项目结构](docs/PROJECT-STRUCTURE.md)。
