# Puuka JLPT Dojo / プーカ JLPT 道場

<p align="center"><img src="public/puuka.png" alt="プーカ" width="180"></p>
<p align="center"><strong>大切な人は、消えない。</strong></p>

在自己的电脑上做 JLPT 真题。文章、表格、选项和答题卡放在同一页；做不完可以保存，交卷后再对照答案和听力原文复盘。

远端题库提供 **59 套 N1 / N2 试卷**。先下载轻量程序，再按需要选择试卷；下载后的练习可以离线使用，不需要注册账号。

![题库首页，可按级别和年份选择试卷](docs/screenshots/home.png)

## 做题与复盘

| 想做什么 | 网站中的用法 |
| --- | --- |
| 只下载需要的试卷 | 按级别、年份筛选并批量选择，查看大小后下载 |
| 按原卷顺序练习 | 以「問題」为单位展示正文和小题，用侧栏或答题卡切换 |
| 记下不确定的地方 | 给整组题添加待检查标记，或在该组笔记中写下思路 |
| 分几次做完 | 保存答案、笔记、用时、页面位置和听力进度，下次继续 |
| 练习听力 | 调整播放速度，前后跳转，按小题定位；同段对话的小问共用起点 |
| 交卷后检查 | 区分正确、错误和未答题，查看参考答案、来源说明和听力原文 |
| 再做一遍 | 开始新一轮练习，保留之前的作答记录 |

## 第一次使用

### Windows

1. 从[浙大 GitLab](https://git.zju.edu.cn/3240104224/puuka-jlpt-dojo)下载[项目 ZIP](https://git.zju.edu.cn/3240104224/puuka-jlpt-dojo/-/archive/master/puuka-jlpt-dojo-master.zip)，完整解压到固定文件夹，例如 `D:\Puuka-JLPT-Dojo`。不要在压缩包内运行。
2. 双击 **部署网站.cmd**。已有 Node.js 20 或更新版本时会直接使用；否则下载官方 LTS 便携版并校验 SHA256。
3. 部署完成后，双击 **启动网站.cmd**，打开 <http://127.0.0.1:3300>。
4. 在首页刷新远端目录，选择试卷下载，再开始练习。**保持服务窗口开着**，关闭窗口即停止网站。

不需要安装 Git、Python 或全局 npm 包，也不需要管理员权限。部署通常只做一次，以后直接启动即可。程序包不含试卷和音频，首页支持单套下载或按级别、年份批量选择。

全部题库的音频约 **1.4 GiB**，不必一次下载。首页会显示每卷下载大小；请为选择的题库及下载临时文件预留空间。便携运行环境默认位于项目 `.runtime/`，项目在 C 盘时改放 `D:\Puuka-JLPT-Dojo-runtime`，不修改系统 PATH。

### 已有 Node.js 的用户

需要 Node.js 20 或更新版本。在项目目录运行：

```sh
npm start
```

然后访问 <http://127.0.0.1:3300>。项目没有第三方 npm 运行依赖，无需先执行 `npm install`。一键部署脚本面向 Windows；其他系统可用已有 Node.js 启动服务。

## 更新与备份

网页设置中可以检查并安装更新，也可以关闭服务后运行 **更新网站.cmd**。程序更新来自主仓库的 `master` 分支，只更新程序，不附带下载题库。首页「刷新远端目录」从独立题库仓库获取可用试卷；下载和更新试卷均由用户选择。网页默认会检查新版本，安装仍需确认；**完成后手动重启服务并刷新网页**。

作答记录保存在本机 `data/progress.json`，浏览器也会保留一份。它们不会通过 GitLab 同步到其他电脑。换电脑、移动项目或清理浏览器前，请先在设置中**导出进度 JSON**；在新环境中导入即可恢复。导入会替换当前记录，不会合并。

复盘页面导出的文字报告适合查看、打印，不能用来恢复进度。详细步骤及常见问题见[使用指南](docs/USER-GUIDE.md#备份和换电脑)。
