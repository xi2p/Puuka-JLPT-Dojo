整理日期：2026-10-30（Asia/Shanghai）。本文件及分册用于在删除旧对话后接续开发、修复、试卷转换和校对，不依赖旧聊天截图。

## 先读这一页

这是一个 Windows 本机 JLPT 真题练习网站。程序为 Node.js 原生 HTTP 服务和原生 HTML/CSS/JavaScript，没有数据库、构建步骤或第三方 npm 运行依赖。用户从扫描 PDF、Word、独立答案及整轨音频中整理出文字题库，下载到本机后练习，记录留在本机。网站每页呈现一个完整的「問題」题组，分为言語知識・読解和聴解。

当前程序仓库：[GitHub / Puuka-JLPT-Dojo](https://github.com/xi2p/Puuka-JLPT-Dojo)，`master`；当前题库仓库：[浙大 GitLab / puuka-jlpt-dojo-lib](https://git.zju.edu.cn/3240104224/puuka-jlpt-dojo-lib)，`master`。本地项目为 `F:\CodexWorkspace\日语学习\JLPT_Website`；其 `exams/` 是独立题库 Git 仓库，运行卷通常位于 `exams/exams/<id>/`。不要因为双层 exams 看起来重复就再次移动或删除。

截至整理时共有 **59 套、1,062 个题组、5,955 题**：N2 30 套、N1 29 套；69 题不计分，实际计分 5,886 题。6 套省略整套聴解。`n1-2025-07` 因严重缺件没有发布。视觉校对已逐套完成现存资料可支持的工作，41 套一般核对完成，18 套保留来源限制；不是「全库已认证等同正式原卷」。

最需要记住的要求：不在 C 盘新增工具或大缓存；保护个人进度，测试用独立文件和端口；制作和测试禁止播放音频；文字与版式忠于来源，疑题不猜补、不强行计分；完成后不要关机。原来的批次已结束，不应仅因看到旧自动化提示就重新开始。
