# 01 用户要求、产品约定与决定变更

本册记录原对话中长期有用的要求。`Mxxxx` 对应本地 [可见文字存档](archive/conversation-text.md) 的消息编号；用户通道中也含自动化重放文本，因此不能把每条都当成新的人工授权。本次任务的新指令优先。

## 网站是什么

用户希望在电脑浏览器中做扫描版 JLPT 真题，不想直接在 PDF 上作答或打印。网站只需本机访问，无公网部署、注册和账户系统。题目应成为可选择、可缩放的文字，不能用整页扫描图代替转录。每套试卷分言語知識（文字・語彙・文法）・読解与聴解，每页展示完整的一个「問題」及其全部关联小题，下方有交互答题卡，支持保存退出、续做和交卷统计。（M0001）

保留离线可用、本机记录、重复练习和复盘体验。统计为答对数量和正确率，不擅自换算官方量尺分或判断合格。参考时长不是强制倒计时，不自动交卷。正确答案、听力原文和逐题播放入口在交卷复盘中开放；「播放本题」是用户主动播放功能，制作人员不得用它自动验收。

## 界面中的具体要求

| 主题 | 最终要求和理由 | 原消息 |
| --- | --- | --- |
| 题面 | 保留原有题号、原文、选项顺序、目标词下划线、星号、段落、脚注和图表关系；不能为省事概括或重排成另一种信息结构 | M0753 |
| 组说明 | 通用「問題…選びなさい」只出现于题组说明，不再粘进首小题；阅读正文和必要空格不是可删除的重复说明 | M0716、M0718、M0744 |
| 检查标记 | 每道小题独立标记，不能只标整组 | M0721 |
| 标记入口 | 题号下面放明显的空心旗，点后为实心，再点取消；不要仅靠点击题号或改变其对错颜色暗示标记 | M0724—M0734 |
| 旗子布局 | 与题号留适当距离，尺寸可见；旗子和第一排选项同排，选项靠近题干，不能旗子独占中间一整行撑开选项 | M0729、M0732、M0800 |
| 左侧目录 | 保留「問題、题类、已答/总题数」对齐；标记数量在最右边，位于已答/总题数右侧，不使不同题类错位；不换行 | M0734、M0736 |
| 答题卡 | 题组答题卡与整卷答题卡都不放旗子；旗子只在题面及目录统计中呈现 | M0740 |
| 作答记录 | 进行中和已交卷都进入列表；进行中可以直接回到上次位置；可指定删除任意一次，包括进行中的记录 | M0710 |
| 服务状态 | 服务窗口关闭、网页仍在操作时必须显示断开；恢复后尝试补存，不能仍显示已经安全保存 | M0705 |
| 听力复盘 | 按小题定位真实音轨；同段对话的两个小问共用起点；定位后立即播放，不是仅显示时间 | M0022 |

阅读段落必须对照原页，不按句号机械拆分。信件、通知、A/B材料、竖排、下划线引用和最后的信息检索图表都属于要求范围，2017.7 N2只是指出问题的例子，不是只改这一套。先修正数据中的段落和布局结构，不能仅调行距掩盖。（M0753、M0755）

对来源原本没有的框线、表头、说明文字，也不能凭习惯添加。宽表和竖排内容在材料自身范围内滚动，手机不能把整页撑宽；阅读正文仍须为可选择文字。确实无法可靠重建的必要小图可使用来源局部裁图，不恢复整份原件下载入口。

## 命名、图片和文案

最终名称是 **Puuka JLPT Dojo / プーカ JLPT 道場**，纪念用户喜爱的角色プーカ。此前有 KOTOBA 等名称；展示和新代码统一现名，但用于迁移旧进度的历史存储键应保留兼容，不能为了清除旧字样而让用户丢记录。（M0040、M0095）

用户提供 `public/favicon.png` 作为网页图标，`public/puuka.png` 应自然融合首页设计，可以放底部，并结合台词「大切な人は、消えない。」。现有墨绿、米白设计及首页底部角色区域是已选用的方案，不应无故重做。（M0095、M0097）

README 首先给普通用户讲功能、部署、启动和操作；技术信息保留在后面的维护文档。文字踏实、准确、少 AI 味，不要华丽宣传或把实现机制塞进用户流程。部署脚本和启动脚本应分开，让不懂技术的用户可以部署；程序更新后说明重启服务和刷新页面。（M0095、M0652、M0702）

## 运行资料和磁盘

- 根目录 `exams/` 集中试卷运行内容，每套独立子目录；个人作答记录不属于试卷素材。（M0033、M0036）
- exams 尽量小，只保留 manifest、exam JSON、最终音轨和必要图示。不提供原始 PDF/Word 浏览或下载，不复制 OCR 页图、ASR、脚本、模型、备份进去。（M0040）
- 原件库保持不动；N2 为 `F:\日语\N2历年真题合集1991-2025`，N1 为 `F:\日语\N1历年真题合集`。新增临时输出使用 F 盘项目 `tmp/`；工具和模型复用 D 盘。
- **不要在 C 盘安装或下载工具、模型或大缓存。** 用户曾遇到 C 盘仅剩约 1 GB，明确要求注意；也要求停止无关磁盘调查，不要擅自扫描全盘、迁移缓存或清理。（M0001、M0085、M0089）
- 已有安装在 C 盘的 Node.js/FFmpeg 可使用；「不新增大文件」不等于必须重装现成工具。注意 Python/模型临时目录、浏览器截图和反复载入图片同样可能产生大缓存。
- 优先复用现有识别、脚本和断点，避免重复 OCR/ASR。历史流程强调尽量单代理，疑点才额外核对，以减少额度和重复工作。

## 音频约束

IDM 曾拦截网页音频导致中断，故现用 JSON Base64 → 浏览器 Blob，并保留「选择本机音频」兜底。不要轻易换回普通 `<audio src="...mp3">` 的唯一加载方式。（M0016—M0021）

用户确认高质量 MP3 VBR 压缩方案，要求以后先评估压缩再入库，exams 内不保留原版音轨，原件库已有源文件。（M0321、M0326、M0329、M0331）具体参数和验收阈值见 03。它是有损压缩，不应宣传为数学无损。

**自 M0423 起，禁止将音频向扬声器播放。** 后续定时提示进一步明确：校对、测试、自动化不点击播放/回听，不调用系统播放器；使用离线识别、解码、波形和时间轴。当前维护约定为禁止触发播放，即使静音也不以播放来测试。历史较早记录中「实际播放验收」是旧行为，不能据此恢复播放。确需实际播放须另有用户明确授权。

## 试卷处理的完成标准

用户明确指出「只做 OCR、启动进程或保存断点」不算交付。必须持续到完整题面、全文文章、脚注、图表、独立答案、听力原文及逐题起点核对完毕，写成可作答的运行文件，通过结构、测试、接口和页面验收。（M0127）

按 `manifest.id` 查重，兼容多层目录；同一卷已有成品或制作进程时先续作/核对，不重复导入。修订同一卷保持原 ID 和题目 ID；不要覆盖已验收内容后声称是新增卷。（M0095、M0099）

先处理 2010 年起的新版 N2，再处理 N1；**2010 年前旧制不转换**。早期曾计划旧制，已被 M0350 明确取消。

缺音频、删节/答案版或错版录音、无法完整核验听力时，跳过整套聴解并交付明确标注的文字阅读版，继续后面的试卷；不要为同一缺件反复询问。单题来源不可靠则标注并排除计分，整套文字也不完整则有据跳过，不编造。（M0315、M0353、M0354）

## 个人进度和工作边界

个人 `data/progress.json` 和浏览器正式作答记录必须保护。页面/接口验收用独立 `JLPT_STATE_FILE` 和端口；不通过删除旧记录、恢复旧哈希版本或替换个人文件修测试。发现外部变化应记录，不能擅自回滚。只停止自己启动的测试服务。

不要调用用户端程序自动更新来做开发同步，避免覆盖正在编辑的文件；不要上传原件、个人记录、模型或制作中间文件，不部署公网。试卷转换范围内优先改试卷数据；确需通用呈现能力时依当前用户任务判断，不能把旧自动化的限制扩大成永久禁止修网站。

## 已变更的历史决定

| 旧决定 | 最终决定 | 依据 |
| --- | --- | --- |
| 程序与题库先后都在 GitHub/浙大主仓库，程序更新顺带更新所有题库 | 程序 GitHub，题库浙大 GitLab；用户按套选择下载、更新、移除 | M0662—M0694、M0956 |
| ZIP 试卷导入，支持多层目录 | 已移除试卷 ZIP 导入入口；远端 catalog 按需下载；递归 manifest 扫描仍保留；个人进度 JSON 导入仍保留 | M0338、M0667 |
| 转换时完全不提交推送 | 后期验收后正常提交并推送相关成品，程序和题库分仓；不能强制加入忽略文件或夹带无关改动 | 后期任务说明、M0705 |
| 重写主历史、强制覆盖远端 | 当时已获明确授权并完成，是具体迁移操作，不能解释成每次维护都可以重写历史 | M0667、M0690、M0959 |
| 每次定时只处理一卷，完成一卷结束 | 视觉校对后期要求连续逐套做到整体完成 | M0797 |
| 全部做完关机 | **撤销，完成后不要关机** | M0800 |

最初转换定时续跑为每小时，后改每 30 分钟；后期视觉校对每小时。初批转换任务已删除，视觉校对亦已收尾。不要根据历史频率自动创建新任务。额度不足时保存准确断点，恢复后从未完成处续做；不自动购买额度或使用重置次数。用户不喜欢能继续时过早停工或重复申请已授权本机验证权限。

旧消息中的「睡到早上10点」「本次直接覆盖 GitHub」「完成后关机」均有明确时间/任务范围，不能作为新操作的无限授权。新的批次、自动化和远端变更以当前人类任务为准。
